# Единый стиль страниц главного окна

## Запрос

Привести оставшиеся страницы главного окна к стилю «Общих» (`SettingsView`):
`Form { Section … }.formStyle(.grouped)`, подписи — `FormFooter`, кнопки в строке справа —
`FormActionRow`, переход на другую страницу — `FormNavigationRow`
(`DevDeck/MainWindow/SettingsFormRows.swift`). Страницы, уже сделанные так, не трогать.

## Согласованное поведение

1. **Пробросы портов.** Сгруппированная форма, одна секция: строка «иконка + имя · порт
   (monospacedDigit, secondary) · шеврон», клик открывает команду. Пусто —
   `ContentUnavailableView`, как сейчас. `FormNavigationRow` расширяется иконкой и значением;
   существующие вызовы (страница «Общие») не меняются.
2. **Вкладки агентов.** Без `Table`; сгруппированная форма из трёх секций:
   - «Восстановление»: тумблер, `LabeledContent` «Снимок снят», `FormActionRow` с «Снять снимок»
     (подтверждение перезаписи сохраняется) и «Восстановить сейчас», ошибка оранжевым; подпись
     `claudeTabsIntro`.
   - «Открытые вкладки»: заголовок + caption «каталог · агент»; справа статус и «Открыть» по
     `SnapshotRowAction`. Пусто — `claudeTabsNoSnapshot`.
   - «История»: в заголовке «Перестроить» (+ ProgressView), первая строка — поиск, затем строки
     с «Открыть»; подпись `claudeTabsHistoryIntro`; пустые состояния — `emptyHistoryMessage`.
   - Пути — одна строка, обрезка посередине, полный текст в подсказке.
   - `TableContentHeight.swift` удаляется вместе со своим тестом: других пользователей нет.
3. **Буфер обмена.** Без сегментов «История / Настройки». Master-detail остаётся; в тулбаре окна —
   `.searchable`, фильтр типа, кнопка «Только закреплённые» с состоянием, меню очистки, ⚙ —
   `ClipboardSettingsView` листом с «Готово». Статус над списком. Логика выбора, очистки и алертов
   не меняется; поповер и `ClipboardEntryRow` не трогаются.
4. **Команды и цепочки.** Структура список → редактор сохраняется:
   - нижняя панель «+ Добавить» убирается (меню «+» в тулбаре сайдбара остаётся);
   - заглушка и пустой список — `ContentUnavailableView`;
   - «Команда / Журнал» — сегментированный `Picker` в тулбаре окна по `appModel.detailTab`, без
     `TabView` и внешнего отступа. Писатели `detailTab`: `addCommand`, `addChain`, `duplicate*`
     (→ редактор), поповер «Журнал» (→ журнал), UI-тест `PanelLayoutTests`;
   - внутренний список — стиль сайдбара, drag-to-reorder и «Дублировать» сохраняются.

## Вне рамок

Поведение, модели, конфиг, локализация (кроме необходимых новых строк в EN и RU), поповер,
сайдбар, страницы на сгруппированной форме, `project.pbxproj`.

## Проверки

- Полный `xcodebuild test` зелёный.
- Изолированный Debug-запуск с `--dev-data-directory` в отдельный временный каталог, тестовый
  config (команды, демон с портом, цепочка); скриншоты четырёх страниц в светлой и тёмной теме,
  сравнение с «Общими».

## План

1. `FormNavigationRow`: иконка и значение (необязательные).
2. Пробросы портов → форма.
3. `ClaudeTabsView` → форма; удалить `TableContentHeight` и его тест.
4. `ClipboardView` → тулбар + лист настроек.
5. Рабочее место команд: тулбарный `Picker`, `ContentUnavailableView`, без нижней панели.
6. Тесты, изолированный запуск, скриншоты, просмотр diff, локальный коммит.
