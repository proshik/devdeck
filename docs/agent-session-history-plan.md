# DevDeck — история сессий агентов и открытие вкладок по одной

> Статус: **план, к реализации**. Без явной просьбы **не коммитить** (см. `CLAUDE.md`).
> Предшествующее: `docs/claude-tabs-restore-plan.md`, `docs/opencode-sessions-plan.md`.

## Зачем

Раздел «Вкладки агентов» показывает зеркало открытого: закрыл вкладку — через несколько секунд
её там нет. Пользователю нужно другое: увидеть и вернуть вкладку, закрытую вчера, и открывать
записи **по одной**, а не только «восстановить всё после перезагрузки».

## Проверенные числа (замерено на машине пользователя)

| окно | транскриптов Claude | объём |
|---|---|---|
| 7 дней | 230 | 270 МБ |
| 14 дней | 328 | 536 МБ |
| 30 дней | 580 | 1055 МБ |
| всё | 787 | 1126 МБ |

opencode: 2 сессии в базе, листинг через CLI, стоит ~0.44 с.

Отсюда два решения. **Окно — 7 дней**: оно единственное реально сокращает чтение (в 4 раза),
месяц почти ничего не отсекает, потому что пользователь активен. И **справочник на диске**:
разговор читается только ради названия, название меняется редко, а дата изменения файла видна
без чтения — значит, второй раз читать нечего.

## Зафиксированные решения

1. **Окно 7 дней** по последней активности — и как граница списка, и как условие «файл можно не
   открывать вовсе». Константа в одном месте.
2. **Справочник переживает перезапуск.** `~/Library/Application Support/DevDeck/agent-sessions.json`
   через `PrivateFile` (0600), как все прочие файлы приложения: он содержит названия разговоров и
   пути проектов. Нынешний кэш живёт в памяти, поэтому «несколько секунд» повторялись при каждом
   запуске; с диском они разовые.
3. **Строится по требованию**, при открытии страницы и по кнопке обновления. Никакого таймера:
   это не то, что должно работать в фоне.
4. **Инкрементально.** Запись переиспользуется, если путь и mtime совпали; иначе файл читается
   заново. Для opencode инкрементальности нет — его листинг дёшев и отдаёт всё сразу.
5. **Открытие по одной** доступно и для открытых сейчас вкладок, и для закрытых: одна строка —
   одно действие, никакого «восстановить всё» на этой странице.

### Task 1: Каталог сессий за окно

**Файлы:** создать `DevDeck/ClaudeTabs/SessionCatalog.swift`; правки в
`AgentSessionProvider.swift`, `TranscriptIndex.swift`, `OpencodeSessionProvider.swift`;
тесты — новый класс.

- [ ] **Шаг 1: `AgentSession` получает каталог**

Сейчас у него `id`, `title`, `lastActivity`. Чтобы открыть закрытую вкладку, нужно знать, **где**
она была: добавить `var directory: String`. Оба поставщика заполняют его — Claude из каталога
проекта, opencode из поля `directory` листинга.

- [ ] **Шаг 2: перечисление за окно**

В `AgentSessionProvider` добавить:

```swift
    /// Everything this agent remembers whose last activity falls inside the window — across all
    /// projects, not one directory. Used by the history list, never by the capture path.
    func recentSessions(since: Date) -> [AgentSession]
```

`ClaudeSessionProvider`: обойти `~/.claude/projects/*`, **пропуская файлы, чей mtime старше
окна, не открывая их** — это и есть вся экономия. Для остальных взять последнюю строку
`ai-title`, как уже умеет `TranscriptTitleScanner`.

`OpencodeSessionProvider`: листинг CLI отдаёт `updated`; отфильтровать по окну. Листинг привязан
к каталогу, поэтому спрашивать по каждому каталогу, который встречается в уже известных записях
каталога-справочника, плюс по каталогам открытых вкладок.

- [ ] **Шаг 3: справочник на диске**

```swift
/// A remembered session title, and what it took to learn it.
///
/// `sourcePath`/`sourceModifiedAt` exist so the next build can skip a file it has already read:
/// a transcript is opened only to learn its title, and the title changes far less often than the
/// file does not.
struct CatalogEntry: Codable, Equatable {
    var provider: String
    var sessionID: String
    var title: String
    var directory: String
    var lastActivity: Date
    var sourcePath: String?
    var sourceModifiedAt: Date?
}
```

`SessionCatalog` — загрузка/сохранение через `PrivateFile`, и чистая функция слияния:

```swift
    /// Entries whose source is unchanged are reused as-is; everything else is rebuilt. Pure so the
    /// "did we avoid the re-read" property is testable without touching a disk.
    static func merge(cached: [CatalogEntry], rescanned: [CatalogEntry]) -> [CatalogEntry]
```

- [ ] **Шаг 4: тесты**

Окно отсекает старое; запись с совпавшим mtime переиспользуется (счётчик чтений не растёт —
фейк, считающий обращения, иначе тест ничего не проверяет); изменившийся файл перечитывается;
битый справочник читается как пустой; round-trip; права файла 0600.

### Task 2: Страница и открытие по одной

**Файлы:** правки в `DevDeck/MainWindow/ClaudeTabsView.swift`, `ClaudeTabsModel.swift`,
`TabRestorer.swift` (если понадобится), `L10n.swift`; тесты.

- [ ] **Шаг 1: открыть одну запись**

Метод модели `open(_ session: AgentSession)`: команду строит поставщик (`command(resuming:in:)`),
выполняет `TabRestorer` одним действием `.newTab`. Никаких планировщиков и инвариантов — это
явное действие пользователя, а не восстановление после перезагрузки.

- [ ] **Шаг 2: страница**

Сверху — открытые сейчас вкладки, как теперь, но у каждой строки появляется «открыть».
Ниже — раздел истории: записи каталога за окно, свежие первыми, **исключая те, что уже открыты**
(сопоставление по `sessionID`), с полем поиска по названию и каталогу. У каждой строки — «открыть».

Кнопка обновления строит каталог заново. Пока строится — индикатор; страница не должна
выглядеть замершей на те секунды, что идёт первое чтение.

- [ ] **Шаг 3: строки L10n** — EN/RU парами, как всё остальное.

- [ ] **Шаг 4: тесты** — исключение уже открытых из истории; фильтр поиска; что `open` вызывает
исполнителя ровно одним действием с командой нужного поставщика.
